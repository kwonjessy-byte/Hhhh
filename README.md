# 포토 다이어리

캘린더에 하루 한 장씩 사진을 남기고, 나중엔 친구와 서로의 사진을 공유해서 볼 수 있는 웹앱.

## 진행 상태

- [x] **1단계** — 캘린더 UI + 혼자 쓰는 사진 촬영/저장 (이 커밋)
- [ ] **2단계** — Vercel/Netlify 등에 배포해서 실제 링크로 접속 가능하게 만들기
- [ ] **3단계** — 공유 백엔드(Firebase/Supabase 등) 연결, 사용자 구분, 나와 친구 사진을 같은 캘린더에서 보기

## 1단계 사용법

별도 설치 없이 정적 파일만으로 동작합니다.

```bash
# 이 폴더에서 아무 정적 서버로 열면 됩니다
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

- 캘린더에서 날짜를 누르면 그날의 사진을 촬영/확인할 수 있습니다.
- 모바일 브라우저(사파리 등)에서 열면 카메라로 바로 촬영할 수 있습니다.
- 사진은 현재 **이 기기의 브라우저(localStorage)에만** 저장됩니다. 다른 기기나 친구와는 아직 공유되지 않습니다 (3단계에서 추가 예정).

## 다음 단계

2단계(배포)와 3단계(공유 백엔드)는 별도로 진행이 필요합니다. 특히 배포는 Vercel/Netlify 계정 연결이 필요해서 진행 방식을 먼저 상의하는 게 좋습니다.
